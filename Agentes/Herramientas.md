# Herramientas

> Qué más puede usar Claude además de leer y escribir notas: cómo se activa cada herramienta y cómo pedírselo.

## Claude en Chrome

Claude usa **tu** Chrome, con las sesiones que ya tenés abiertas (Gmail, LinkedIn…).

1. Instalá la extensión **Claude** desde la Chrome Web Store.
2. Iniciá sesión en la extensión con tu cuenta de Claude.
3. Pedí: "en Chrome, abrí LinkedIn y buscá ofertas de React".

Antes de mandar, publicar o comprar algo, Claude te pide confirmación.

## Browser integrado (app de escritorio)

Un navegador aparte, dentro de la app de Claude. No usa tus sesiones de Chrome.

- Pedí: "abrí la web de X y resumime los precios".
- Sirve para leer páginas, probar tu web en local y sacar capturas.

## Figma

Claude lee y edita diseños de Figma.

1. En Claude: **Configuración → Conectores → Figma → Conectar**.
2. Pegá el link de un frame y pedí: "pasame este diseño a código".

## Gmail, Calendar y Drive

1. **Configuración → Conectores** → conectá el que quieras.
2. Pedí: "¿qué tengo mañana?" o "buscá el mail de X".

## Tareas programadas

Claude corre algo solo, cada cierto tiempo.

- Pedí: "todos los lunes a las 9, revisá mis ideas y ordenalas".
- Se ven y se borran desde la app, en **Tareas programadas**.

## Agregar otra herramienta

- Pedile a Claude: "¿hay un conector para Notion?". Si existe, te dice cómo conectarlo.
- Cuando la actives, sumala acá en una línea.
